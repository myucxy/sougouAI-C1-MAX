## V0141 实验预发布

发布日期：2026-11-23。功能版本：V0141（2026-11-22）。作者：清风惹尘丶。

**本次为源码实验预发布，附件不含 `SOGOUOTA.BIN`，不能下载后直接刷机。** 原厂镜像、完整 OTA、本机身份数据和个人录音不公开分发；构建需要使用者自行提供匹配且有权使用的私有基线输入。

### 主要功能

- 保留原录音与回放，并与小智、MP3 模式交接音频资源。
- 小智提供按住说话、单击开停、连续对话三种模式，设置页显示当前选择，包含回复字幕和亮屏连接处理。
- 全屏 MP3 播放、歌单入口、单击播放、长按删除确认、右上角电量；忽略 macOS `._*.mp3` 等点开头文件。
- MP3 支持单曲循环、全部循环、顺序播放、随机播放，时间行左侧图标可切换，模式在本次开机内保留。
- MP3 模式下，录音物理键单击播放／暂停、双击下一首并播放、长按约 0.6 秒上一首并播放；触屏使用实际控件功能。
- 进入设置保持音乐播放，播放中切到小智先确认并暂停；MP3／小智上滑显示底部半屏音量面板。
- 保留清风开机动画“风过，尘起。”。

### 附件

- `c208-v0141-experimental-source.zip`：当前标签对应的公开源码、文档、素材和许可证。
- `SHA256SUMS.txt`：上述源码压缩包的 SHA-256，用于核对下载完整性。

附件仅从 Git 跟踪的公开文件生成，不包含 `_local/`、原厂完整镜像、完整 OTA、身份文件或个人音频。GitHub 自动提供的 Source code 下载同样是源码。

### 已有验证

- V0141 原有 23 组软件回放通过记录保留于仓库，包含播放模式、按键、触屏、音量、录音及语音路径；它们不是本次重新执行的全部实机测试。
- 整理后在作者本机，用保留的已核对静态库重新构建，OTA 与原发行 V0141 逐字节一致。
- 发布工作流运行五组主机 C 测试（ASan／UBSan）、四项工具测试和公开文件检查，再上传并回读核对附件。

软件回放使用了硬件与文件系统模型，不能证明整机适配、实际音频表现、USB 枚举、长期稳定性或断电恢复能力。

### 刷机风险与备份

**非官方实验固件可能导致黑屏、无法开机、录音丢失或需要拆机恢复。** 相同型号文字或处理器不保证主板和外设完全适配。

有匹配编程器并具备拆机经验的用户，建议在首次刷机前先拆机读取本机完整 SPI Flash；核对芯片、电压和方向，独立读取至少两次并比较长度与 SHA-256，保存本地副本。原始镜像与录音、配置需要分别备份。当前尚未完成本机编程器整片回写实测，备份不代表一定能救回。

V0141 保留原启动区、Rec 和 DSP，但没有新增增强 Recovery、USB 救机投包、自动镜像备份或自动回滚。没有已验证通用的实体组合键救机方法。
