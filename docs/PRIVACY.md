# 隐私与公开文件

原始 Flash 镜像可能包含设备信息、标识、启动控制及厂商数据。完整 OTA 沿用部分原厂区，所以即使新增源码没有密码，也不能据此把整个 OTA 当作已脱敏文件。

以下内容仅保留本地，不应上传仓库、Issue、日志附件或 GitHub Release：

- 原始 `.bin`、完整 `SOGOUOTA.BIN`／`FOTA.BIN`、SPI 备份及未知来源的固件。
- `XZAUTH0.CFG`、`XZAUTH1.CFG`。其中含身份种子与使用计数；不要发给他人，不要克隆到其他设备，不要用旧备份覆盖设备上更新后的计数。
- Wi-Fi 密码、账号令牌、个人录音、音频故障原始录音、商业音乐、未审核的设备日志和抓包。
- 含用户电脑目录、SSH 配置、私钥或迁移配置的文件。

`.gitignore` 排除 `_local/`、构建输出和上述常见二进制后缀；`scripts/check_public_tree.py --tracked` 会额外检查实际跟踪文件，避免被 `git add -f` 绕过忽略规则。

检查工具能识别已知凭据特征、原作者电脑路径、外部符号链接和不允许的产物类型；它不能证明不存在任何形式的隐私。新增数据和附件仍需内容审阅。

公开的验证 JSON 为保留测试报告的脱敏副本；原电脑绝对路径已替换为占位符。这些文件与原报告的字节散列不同，不应沿用原报告散列作为其内容校验。

公开 TLS 文件只有根证书与公开名称数据，不含服务器私钥、设备种子或用户令牌。测试里的示例密码和示例令牌只应是固定测试值。

设备首次身份由 `prepare_xiaozhi_identity.py` 或升级准备工具在本地生成。运行升级准备工具会写入设备目录；公开仓库不会携带任何可供多人共用的真实身份文件。
